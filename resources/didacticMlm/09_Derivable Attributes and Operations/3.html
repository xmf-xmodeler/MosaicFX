You correctly identified all five derivable attributes. Good job! Here is an explanation for all derivable attributes:

  1. age: Integer in class Customer: The age can be calculated on the basis of the date of birth of a customer.
  2. numberOfTickets: Integer in class Reservation: The number of tickets within a reservation correspond to the number of linked Ticket objects.
  3. totalPriceOfReservation: Float in class Reservation: The total price corresponds to the sum of all linked ticket prices.
  4. isAvailable: Boolean in class Ticket: A ticket for a seat is available if it is not yet reserved, i.e., not linked to a Reservation object.
  5. availableSeats: Integer in class MovieShow: We can determine the number of available seats by retrieving the number of seats from the indirectly linked Hall object.

Good job you found all the deficient classes. When you look at them you might be able to see which issues may arise from having these attributes. The issues of age are obvious. Since, it depends on the date of birth and changes every year one would have to constantly check if it needs to be updated. Especially, problematic is the price attribute in Reservation because the price needs to be calculated individually depending on the number of tickets, their price, and the extra cost.
