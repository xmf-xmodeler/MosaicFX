LU3 - Multiplicities of Attributes

Theoretical Background

Similar to associations, each attribute must specify a multiplicity. The multiplicity of an attribute specifies the number of values that may be or must be entered for its slots. If the maximum multiplicity of an attribute is higher than one, a sequence of values may be entered. This corresponds to known data structures like arrays or lists that contain multiple values. In UML, the default multiplicity is 1..1, shown as [1] for each attribute.

Multiplicity of attributes cannot be altered in UML-MX. But slots may still contain no value or multiple values. Since this violates the default multiplicity of 1..1, the constraint violation is shown in the object. The example model showcases slots with 0, 1, and multiple values. The respective objects thus displays multiple error messages.
